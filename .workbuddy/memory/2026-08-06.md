## 创建 GitHub Actions 发布工作流
- 新增 `.github/workflows/release.yml`：push `v*` tag 时自动跨平台打包并发布到 GitHub Release。
- 按平台拆分到不同 runner：Android/Linux 用 ubuntu-latest；Windows 用 windows-latest；iOS/macOS 用 macos-latest（苹果平台必须在 macOS 构建）。
- 架构拆分：Android 用 `--split-per-abi`（armeabi-v7a/arm64-v8a/x86_64）；Linux 矩阵 [x64,arm64]（arm64 装 aarch64 交叉工具链）；Windows 矩阵 [x64,arm64]；macOS 矩阵 [arm64,x64]。
- iOS 用 `--no-codesign` 产出未签名 Runner.app；macOS 用 `DEVELOPMENT_TEAM=""` ad-hoc 签名；Android 走模板默认 debug 签名配置打 release。
- 收尾用 `softprops/action-gh-release@v2` 汇总所有 artifact 到对应 tag 的 Release。
- 注意：Flutter 版本 pin 在 3.44.1（项目验证环境）；若某 runner 上不存在该版本，可改为 `channel: stable` 不锁版本。
