# 2026-08-26 工作日志

## 修复 ListTile 被 DecoratedBox 包裹的非致命告警
- 现象：运行时反复抛 "ListTile background color or ink splashes may be invisible"；按 visualDensity(0,-3.65) 定位到 PC 侧边栏的 ListTile。
- 根因：
  - `lib/views/home/pc/layout/sidebar.dart` 的 `sidebarItem` 用 `Container(decoration: BoxDecoration(color: _selectedBgColor=0xFFFFEEF3, borderRadius:8))` 包裹 ListTile。
  - `lib/views/playlist/playlist.dart` 的歌单操作 bottom sheet `_buildOptionTile` 的 ListTile 被带 cardColor 背景的 Container 包裹。
- 修复：
  - sidebar.dart：把外层 `Container` 改为 `Material(color: isSelected?_selectedBgColor:transparent, shape: RoundedRectangleBorder(borderRadius:8))`。
  - playlist.dart：`_buildOptionTile` 的 ListTile 外包 `Material(color: Colors.transparent)`。
  - `lib/widgets/add_to_playlist_dialog.dart` 的 ListTile 无 BoxDecoration 父级，无需改。
- 验证：`flutter run -d windows` 启动后该告警消失。
