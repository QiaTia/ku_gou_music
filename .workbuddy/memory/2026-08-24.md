# 2026-08-24 工作日志

## 在 Windows 桌面成功运行 ku_gou_music
- Flutter 3.44.1 / Dart 3.12.1，`flutter run -d windows` 构建并启动成功。
- 解决 Windows 桌面构建失败：jni 插件（被 path_provider_android 间接引入）编译时 MSVC 报 “无法打开包括文件: jni.h”。
  - 根因：jni 包 `src/CMakeLists.txt` 在 Flutter 构建分支用非 REQUIRED 的 `find_package(JNI)`，其 `JNI_INCLUDE_DIRS` 未正确传入 MSVC 的 include 命令行。
  - 修复1（持久化）：用户级环境变量 `JAVA_HOME` 指向 HBuilderX 自带的 Amazon Corretto JDK 17（`C:\Program Files\HBuilderX\plugins\amazon-corretto`），含 `include/jni.h`、`include/win32/jni_md.h`、`lib/jvm.lib`。
  - 修复2（项目本地）：在 `windows/CMakeLists.txt` 的 `add_subdirectory(flutter)` 前加入
    `if(WIN32 AND DEFINED ENV{JAVA_HOME}) include_directories("$ENV{JAVA_HOME}/include" "$ENV{JAVA_HOME}/include/win32") endif()`。
- 运行时告警（非致命）：ListTile 被 DecoratedBox 包裹，导致 ink splash/背景不可见（Flutter assertion），不影响启动与数据加载。
